# 会员续费功能测试指南

## 测试场景

### 场景1：会员未到期续费（累加天数）

**步骤：**
1. 使用测试账号登录（Test1234/password123）
2. 查看当前会员状态
   - 进入"会员中心"
   - 记录当前到期日期和剩余天数
3. 兑换新卡密
   - 进入"兑换中心" 或 点击"兑换卡密"
   - 输入卡密码（如：True-ABCDEFGHJKLMNPQRSTUWXYZ2）
   - 点击"立即兑换"
4. 验证结果
   - 查看新的到期日期
   - 确认天数已累加
   - 检查兑换历史

**预期结果：**
```
原到期日期：2025-12-20
剩余天数：13天
兑换：30天月卡
新到期日期：2026-01-19（原日期+30天）
新剩余天数：43天
```

## SQL验证

### 查看用户会员信息
```sql
SELECT 
    username,
    role,
    member_expire,
    CASE 
        WHEN role = 2 THEN '会员'
        WHEN role = 1 THEN '普通用户'
        ELSE '其他'
    END as role_name,
    CASE 
        WHEN member_expire IS NULL THEN '未开通'
        WHEN member_expire < NOW() THEN '已过期'
        ELSE CONCAT(
            EXTRACT(DAY FROM (member_expire - NOW())), 
            '天后到期'
        )
    END as status
FROM users 
WHERE username = 'Test1234';
```

### 查看兑换历史
```sql
SELECT 
    order_no,
    card_code,
    duration,
    redeem_time,
    expire_time
FROM member_orders
WHERE user_id = (SELECT id FROM users WHERE username = 'Test1234')
ORDER BY redeem_time DESC
LIMIT 5;
```

## 注意事项

1. **时间累加验证**
   - 确保累加的是剩余天数，不是从今天开始
   - 测试时可以手动修改数据库中的到期时间

2. **边界情况**
   - 到期前1天续费
   - 到期当天续费
   - 到期后续费

3. **多次续费**
   - 连续兑换多张卡密
   - 验证天数累加是否正确
