### 中间件

#### 1. 认证中间件

```go
func JWTAuth(jwtManager *auth.JWTManager) gin.HandlerFunc {
    return func(c *gin.Context) {
        token := c.GetHeader("Authorization")
        claims, err := jwtManager.ValidateToken(token)
        if err != nil {
            c.AbortWithStatus(401)
            return
        }
        c.Set("claims", claims)
        c.Next()
    }
}
```

#### 2. 日志中间件

记录每个请求的详细信息:
- 请求方法和路径
- 响应状态码

## 第三方集成

### 飞牛影视API

**API Base URL**: `http://10.10.10.10:8005/v/api/v1`

**认证方式**:
1. **authorization header**: 用户token
2. **authx header**: MD5签名验证

**主要接口**:
| 接口 | 方法 | 说明 |
|------|------|------|
| /login | POST | 用户登录 |
| /mediadb/list | GET | 媒体库列表 |
| /item/list | POST | 影片列表 |
| /sys/img/{path} | GET | 图片服务 |

**签名算法**:
```go
func generateAuthx(path string, method string, data interface{}) string {
    nonce := generateNonce(6)
    timestamp := time.Now().UnixMilli()
    
    // 计算数据hash
    dataJSON, _ := json.Marshal(data)
    dataHash := md5.Sum(dataJSON)
    
    // 组合签名字符串
    signStr := fmt.Sprintf("%s%s%s%d%x",
        SECRET_KEY, API_KEY, path, timestamp, dataHash)
    
    // MD5签名
    sign := md5.Sum([]byte(signStr))
    
    return fmt.Sprintf("nonce=%s&timestamp=%d&sign=%x",
        nonce, timestamp, sign)
}
```
