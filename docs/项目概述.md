# 飞牛影视用户管理系统 - 项目概述

## 📝 项目简介

飞牛影视用户管理系统是一个完整的Web应用，集成了飞牛影视API，为用户提供影视内容浏览、会员管理、用户认证等功能。系统采用前后端分离架构，后端使用Go语言开发，前端使用React框架。

## 🎯 项目目标

- 提供统一的用户管理平台
- 整合飞牛影视API资源
- 实现会员权益系统
- 构建现代化的用户界面
- 提供完善的管理后台

## ⭐ 核心功能

### 用户端功能

1. **用户认证**
   - 邮箱注册（带验证码）
   - 账号密码登录
   - JWT Token认证
   - 自动刷新Token

2. **会员系统**
   - 多级会员（免费、银卡、金卡、钻石）
   - 卡密兑换
   - 会员权益管理
   - 观看次数限制

3. **媒体库**
   - 浏览媒体库列表
   - 查看影片详情
   - 海报封面展示
   - 评分和简介
   - 分类筛选

4. **个人中心**
   - 个人信息管理
   - 会员信息查看
   - 观影历史
   - 收藏功能

### 管理端功能

1. **用户管理**
   - 用户列表查询
   - 用户详情查看
   - 会员信息管理
   - 用户状态控制

2. **卡密管理**
   - 批量生成卡密
   - 卡密查询
   - 使用记录
   - 卡密禁用

3. **系统设置**
   - 邮件配置
   - 系统通知
   - 日志查看

## 📊 系统特点

### 1. 安全性

- **JWT双Token机制**: Access Token + Refresh Token
- **密码加密**: Bcrypt加密存储
- **权限控制**: 基于角色的访问控制(RBAC)
- **请求限流**: 防止恶意请求
- **CORS配置**: 跨域安全策略

### 2. 性能优化

- **Redis缓存**: 热点数据缓存
- **图片懒加载**: 优化首屏加载
- **分页查询**: 大数据量分页处理
- **连接池**: 数据库连接复用
- **CDN加速**: 静态资源加速

### 3. 用户体验

- **响应式设计**: 适配多种设备
- **毛玻璃效果**: 现代化UI设计
- **流畅动画**: 页面过渡动画
- **加载提示**: 友好的加载状态
- **错误处理**: 清晰的错误提示

### 4. 可维护性

- **模块化设计**: 清晰的代码结构
- **统一规范**: 代码风格统一
- **详细注释**: 关键逻辑注释
- **日志记录**: 完善的日志系统
- **配置化**: 灵活的配置管理

## 🔄 业务流程

### 用户注册流程

```
用户输入邮箱
    ↓
发送验证码邮件
    ↓
用户输入验证码和密码
    ↓
验证邮箱有效性
    ↓
创建本地账号
    ↓
同步创建飞牛账号
    ↓
返回JWT Token
    ↓
自动登录
```

### 媒体浏览流程

```
用户登录系统
    ↓
获取JWT Token
    ↓
访问媒体库列表
    ↓
后端验证Token
    ↓
获取飞牛Token（从Redis）
    ↓
调用飞牛API获取数据
    ↓
前端展示媒体列表
    ↓
点击查看详情
    ↓
加载影片信息和海报
```

### 图片代理流程

```
前端请求图片 (URL带uid参数)
    ↓
后端图片代理接收请求
    ↓
根据uid获取飞牛Token
    ↓
使用Token请求飞牛图片
    ↓
代理返回图片内容
    ↓
浏览器显示图片
```
