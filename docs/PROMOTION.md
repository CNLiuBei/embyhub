# 🎬 EmbyHub - 你的私人影视站管理神器

---

## 🤔 这玩意儿是干嘛的？

如果你有自己的 Emby 或 Jellyfin 影视服务器，想分享给朋友或者做个小型付费影视站，但又不想手动管理用户、收钱、发卡密...

**EmbyHub 就是来解决这些问题的！**

它是一套完整的用户管理系统，帮你搞定从用户注册到收款发货的全流程。你只需要专注搞片源，剩下的交给它。

## 🚀 快速部署

### 方式一：Docker（推荐）

最简单的方式，适合大多数人：

```bash
# 克隆项目
git clone https://github.com/CNLiuBei/embyhub.git

# 进入目录
cd embyhub

# 一键启动
docker compose up -d
```

启动后访问：
- 前端界面：`http://你的IP:54681`
- 默认账号：`admin` / `admin123`

### 方式二：二进制部署

适合不想装 Docker 的朋友：

1. 去 [Releases](https://github.com/CNLiuBei/embyhub/releases) 下载对应系统的可执行文件
2. 准备好 PostgreSQL 和 Redis
3. 配置环境变量后直接运行

### 方式三：源码编译

适合想魔改的开发者：

```bash
# 后端（需要 Go 1.24+）
cd backend && go build -o server ./cmd/server

# 前端（需要 Node.js 18+）
cd frontend && npm install && npm run build
```

## ❓ 常见问题

**Q：需要什么服务器配置？**
A：1核1G 就能跑，推荐 2核2G 更流畅。

**Q：支持哪些支付方式？**
A：目前支持卡密充值和支付宝当面付，微信支付在规划中。

**Q：怎么对接 Emby？**
A：在管理后台填入 Emby 地址和 API Key 就行，用户会自动同步。

**Q：没有公网 IP 怎么办？**
A：系统内置 Cloudflare Tunnel，免费内网穿透，自动配置。

**Q：数据安全吗？**
A：支持一键备份，数据都在你自己服务器上。
