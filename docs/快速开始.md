# 快速开始指南

## 环境准备

### 系统要求

- **操作系统**: Linux / macOS / Windows (推荐Linux)
- **内存**: 最低4GB，推荐8GB+
- **硬盘**: 至少10GB可用空间
- **网络**: 需要访问外网（下载依赖）

### 必需软件

#### 1. Go语言环境

**版本要求**: 1.21+

**安装方法**:

```bash
# Linux/macOS
wget https://go.dev/dl/go1.21.0.linux-amd64.tar.gz
sudo tar -C /usr/local -xzf go1.21.0.linux-amd64.tar.gz
export PATH=$PATH:/usr/local/go/bin

# 验证安装
go version
```

**环境变量配置**:
```bash
export GOPATH=$HOME/go
export PATH=$PATH:$GOPATH/bin
export GOPROXY=https://goproxy.cn,direct
```

#### 2. Node.js环境

**版本要求**: 18+

**安装方法**:

```bash
# 使用nvm（推荐）
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
nvm install 18
nvm use 18

# 验证安装
node --version
npm --version
```

#### 3. PostgreSQL数据库

**版本要求**: 14+

**安装方法**:

```bash
# Ubuntu/Debian
sudo apt update
sudo apt install postgresql-14

# CentOS/RHEL
sudo yum install postgresql14-server

# macOS
brew install postgresql@14

# 启动服务
sudo systemctl start postgresql
sudo systemctl enable postgresql
```

**初始化**:
```bash
# 创建数据库
sudo -u postgres psql
CREATE DATABASE feiniu_user_system;
CREATE USER feiniu WITH PASSWORD 'your_password';
GRANT ALL PRIVILEGES ON DATABASE feiniu_user_system TO feiniu;
\q
```

#### 4. Redis服务

**版本要求**: 7+

**安装方法**:

```bash
# Ubuntu/Debian
sudo apt install redis-server

# CentOS/RHEL
sudo yum install redis

# macOS
brew install redis

# 启动服务
sudo systemctl start redis
sudo systemctl enable redis

# 测试连接
redis-cli ping
# 应返回: PONG
```

## 项目安装

### 1. 获取代码

```bash
# 克隆项目
git clone <repository-url>
cd feiniu-user-system

# 查看项目结构
tree -L 2
```

### 2. 后端配置

#### 复制配置文件

```bash
cd backend
cp config.example.yaml config.yaml
```

#### 编辑配置文件

```yaml
# config.yaml
server:
  port: 8080
  mode: debug  # release / debug

database:
  host: localhost
  port: 5432
  user: feiniu
  password: your_password
  dbname: feiniu_user_system
  sslmode: disable

redis:
  addr: localhost:6379
  password: ""
  db: 0

jwt:
  secret: your-secret-key-change-in-production
  access_expire: 15m
  refresh_expire: 168h

email:
  enabled: true
  smtp_host: smtp.example.com
  smtp_port: 587
  username: your-email@example.com
  password: your-email-password
  from_name: 飞牛影视

feiniu:
  enabled: true
  base_url: http://10.10.10.10:8005
  admin_user: admin
  admin_pass: admin_password
  api_key: your_api_key
  secret_key: your_secret_key
```

#### 安装依赖

```bash
# 下载Go依赖
go mod download

# 验证依赖
go mod verify
```

#### 初始化数据库

```bash
# 运行数据库迁移（自动创建表）
go run cmd/server/main.go

# 或者使用migrate工具
migrate -path migrations -database "postgresql://feiniu:password@localhost:5432/feiniu_user_system?sslmode=disable" up
```

### 3. 前端配置

```bash
cd ../frontend

# 安装依赖
npm install

# 或使用yarn
yarn install

# 或使用pnpm
pnpm install
```

#### 环境变量配置

```bash
# .env.development
VITE_API_BASE_URL=http://localhost:8080
VITE_APP_TITLE=飞牛影视用户管理系统
```

```bash
# .env.production
VITE_API_BASE_URL=https://api.yourdomain.com
VITE_APP_TITLE=飞牛影视
```

## 启动服务

### 方法一：使用启动脚本（推荐）

```bash
# 回到项目根目录
cd /vol1/1000/FnHub/feiniu-user-system

# 启动所有服务
./start.sh start

# 查看状态
./start.sh status

# 重启服务
./start.sh restart

# 停止服务
./start.sh stop
```

**脚本功能**:
- 自动检查依赖
- 启动后端服务（端口8080）
- 启动前端服务（端口3000）
- 实时显示日志
- 健康检查

### 方法二：手动启动

#### 启动后端

```bash
cd backend

# 开发模式（热重载）
go run cmd/server/main.go

# 或编译后运行
go build -o server cmd/server/main.go
./server

# 后台运行
nohup ./server > backend.log 2>&1 &
```

#### 启动前端

```bash
cd frontend

# 开发模式
npm run dev

# 或
vite --port 3000
```

## 常见问题

### Q1: 端口被占用

**问题**: 启动时提示端口8080或3000已被占用

**解决方法**:

```bash
# 查找占用进程
lsof -i :8080
lsof -i :3000

# 杀死进程
kill -9 <PID>

# 或修改配置文件使用其他端口
```

### Q2: 数据库连接失败

**问题**: 后端启动失败，提示数据库连接错误

**检查清单**:
- [ ] PostgreSQL服务是否启动
- [ ] 数据库名称是否正确
- [ ] 用户名密码是否正确
- [ ] 防火墙是否允许连接

**解决方法**:

```bash
# 检查PostgreSQL状态
sudo systemctl status postgresql

# 测试连接
psql -U feiniu -d feiniu_user_system -h localhost

# 查看日志
sudo tail -f /var/log/postgresql/postgresql-14-main.log
```

### Q3: Redis连接失败

**问题**: 提示无法连接到Redis

**解决方法**:

```bash
# 检查Redis状态
sudo systemctl status redis

# 测试连接
redis-cli ping

# 启动Redis
sudo systemctl start redis
```

### Q4: 前端依赖安装失败

**问题**: npm install报错

**解决方法**:

```bash
# 清除缓存
npm cache clean --force

# 删除node_modules和package-lock.json
rm -rf node_modules package-lock.json

# 重新安装
npm install

# 或使用镜像源
npm install --registry=https://registry.npmmirror.com
```

### Q5: Go依赖下载慢

**问题**: go mod download 非常慢

**解决方法**:

```bash
# 设置国内代理
go env -w GOPROXY=https://goproxy.cn,direct

# 或使用阿里云
go env -w GOPROXY=https://mirrors.aliyun.com/goproxy/,direct

# 清除缓存
go clean -modcache

# 重新下载
go mod download
```
