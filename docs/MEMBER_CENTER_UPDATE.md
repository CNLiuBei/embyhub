
点击按钮后，弹出精美的VIP购买弹窗，包含：

- ✅ 3个套餐选择（月度/季度/年度）
- ✅ 实时购买确认
- ✅ 余额不足提示

### 3. **VIP状态识别**
弹窗会根据用户VIP状态显示：
- 标题：已开通 → "续费VIP会员" | 未开通 → "开通VIP会员"
- 提示：已是VIP会员会显示续期提示

## 🔧 技术实现

### 1. **数据获取**
```tsx
// VIP套餐列表
GET /api/v1/vip/plans

// 用户VIP信息
GET /api/v1/vip/info

// 用户余额
GET /api/v1/balance
```

### 2. **购买流程**
```tsx
// 1. 用户选择套餐
setSelectedPlan(plan)

// 2. 点击确认支付
handleConfirmPurchase()

// 3. 验证余额
if (userBalance < planPrice) {
  message.warning('余额不足，请先充值')
  return
}

// 4. 调用购买API
POST /api/v1/vip/purchase
Body: { plan_id: 1 }

// 5. 成功后刷新
queryClient.invalidateQueries(['vipInfo'])
queryClient.invalidateQueries(['balance'])
window.location.reload()
```

### 3. **状态管理**
```tsx
const [vipPurchaseModalOpen, setVipPurchaseModalOpen] = useState(false)
const [selectedPlan, setSelectedPlan] = useState<VipPlan | null>(null)

// 判断用户VIP状态
const isVip = vipInfoData?.is_vip || false
const vipExpireAt = vipInfoData?.vip_expire_at
```

## 🎯 用户流程

### 场景1：普通用户开通VIP
1. 进入会员中心
2. 看到"开通VIP"按钮
3. 点击按钮，弹出购买弹窗
4. 查看套餐和权益
5. 选择套餐
6. 确认支付
7. 成功开通，页面刷新

### 场景2：VIP用户续费
1. 进入会员中心
2. 看到"续费VIP"按钮和到期时间
3. 点击按钮，弹出续费弹窗
4. 弹窗标题显示"续费VIP会员"
5. 选择套餐
6. 看到续期提示
7. 确认支付
8. 成功续费，时长自动延长

### 场景3：余额不足
1. 选择套餐
2. 点击确认支付
3. 系统提示"余额不足，请先充值"
4. 用户关闭VIP弹窗
5. 点击"充值余额"按钮
6. 兑换充值卡
7. 重新打开VIP购买弹窗
8. 完成购买
